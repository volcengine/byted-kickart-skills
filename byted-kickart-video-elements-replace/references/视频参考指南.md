# 视频参考指南

## 目的与适用场景

当用户意图进行视频元素替换或主动提供参考视频时，使用本指南引导用户提供并校验参考视频，最终获取可直接传给 `submit_high_similarity_task_v2 --ref-video` 的本地绝对路径或公网 URL。

## 支持的输入方式

- 支持用户提供有效的 HTTP(S) 视频链接。
- 支持用户上传本地视频文件。
- 不支持选择 SAAS 资产库内视频。

## 视频规格要求

- 格式：仅支持 `MP4` 或 `MOV`。
- 大小：不超过 50MB。
- 具体时长、分辨率和画幅限制以服务端返回及 CLI `--help` 为准。

## 交互方式

当用户表达视频元素替换意图但尚未提供参考视频时，必须引导：

> 请提供需要进行视频元素替换的参考视频：可以发送视频链接，或上传 MP4/MOV 文件（≤50MB）。请确保拥有该视频的合法使用和改编权。

## 视频处理流程

1. 用户提供公网视频 URL 时，校验 URL 使用 HTTP(S) 协议并保留原始 URL，无需下载或上传。
2. 用户上传本地视频时，获取 CLI 进程可读取的绝对路径。
3. 本地文件提交前校验路径存在、可读、为绝对路径、扩展名为 `.mp4` 或 `.mov`，大小不超过 50MB。
4. 能够读取元数据时记录时长、分辨率和画幅；无法确认时标记为“待服务端校验”，不得声称已通过本地无法执行的校验。
5. 执行 `submit_high_similarity_task_v2` 时通过 `--ref-video` 传入，由 CLI 自动上传本地文件并转换为 URL。
6. 在会话上下文保存输入来源、路径或 URL、已确认的规格和校验状态。

## 向用户反馈

基础校验通过后使用普通正文格式：

```text
✅ 参考视频已接收并通过基础校验
📁 输入来源：[本地文件/公网URL]
📍 素材位置：[仅展示文件名或脱敏后的URL]
📝 校验结果：[格式、大小，以及实际能够确认的元数据]
🔎 元数据校验状态：[已完成；或列出待服务端校验的指标]
```

基础校验失败时明确指出失败文件、实际值、限制和修复建议，不执行提交命令。
