# 视频元素替换指南

## 触发场景

当用户要求替换参考视频中的角色、场景、商品、道具、声音等视频元素时使用本技能。

## 执行流程

### Phase 0: 初始化（提交前确认）

在执行视频元素替换任务前，必须依次引导用户完成以下准备工作。

> 核心规则：所有步骤必须逐一询问，Agent 不得私自跳过任何一步。
> - 必填步骤：用户必须提供有效值才能继续。
> - 可选步骤：Agent 必须主动提示用户可以输入值或选择默认值。
> - 每完成一步，必须明确记录状态已流转至下一步。

**信息收集总览**：
> 1. **参考视频**（必填）：视频链接或上传 MP4/MOV 文件
> 2. **语言设置**（必填）：成片语种，默认中文
> 3. **模型选择**（必填）：Seedance 2.5 或 Seedance 2.0 mini
> 4. **替换素材**（必填）：按用户发送顺序提供需要替换的角色、场景、商品、道具等素材
> 5. **创作提示词**（必填）：说明每个替换素材对应的视频元素和期望效果，最长 5000 字符

1. **参考视频获取（必填）**：向用户发送话术：“请提供需要进行视频元素替换的参考视频：可以发送视频链接，或上传 MP4/MOV 文件（≤50MB）。请确保拥有该视频的合法使用和改编权。”然后阅读 `references/视频参考指南.md`。公网 URL 或校验通过的本地绝对路径映射为 `--ref-video`，不预先上传。成功获取后，必须明确记录状态已流转至下一步。

2. **语言设置（必填）**：向用户发送话术：“成片视频需要使用什么语言？支持中文(zh)、英文(en)、英语-美国(en-us)、巴西葡萄牙语(pt-br)、日语(ja)、西班牙语-墨西哥(es-mx)、印尼语(id)、马来语(ms)、他加禄语(tl)，默认使用中文(zh)。请回复语言代号，或回复‘默认’。”用户回复默认时记录 `zh`；否则按 CLI 支持的枚举设置 `--language`。完成后必须明确记录状态已流转至下一步。

3. **模型选择（必填）**：向用户发送话术：“请选择视频生成模型：① Seedance 2.5（推荐，生成效果更好；模板 ID：978755330）② Seedance 2.0 mini（生成更快、成本更低；模板 ID：1028571394）。请回复序号或模型名称，必须选择一项。”
   - 用户选择 Seedance 2.5 或 `978755330`：设置 `--template-id 978755330`。
   - 用户选择 Seedance 2.0 mini 或 `1028571394`：设置 `--template-id 1028571394`。
   - 未选择有效模型时，必须提示用户重新选择；不得自行决定模型或模板。
   - 完成后必须明确记录模型名称和对应 `template_id`，再流转至下一步。

4. **替换素材获取（必填，逐项收集）**：读取 `references/替换图片指南.md`，向用户发送话术：“请上传需要使用的替换图片，并说明素材类型（角色、场景、商品或道具）。图片支持 JPEG/PNG 本地文件或公网 URL，最多 10 张；本地图片单张不超过 8MB。声音等非图片元素请在下一步创作提示词中说明，素材将按照上传顺序编号。”
   - 用户每发送一张有效图片后，必须立即追加到当前图片列表，并向用户描述当前全部图片及其 index，格式为“图1：xxx内容；图2：xxx内容”，无需在此步骤说明替换对象。
   - 描述全部图片后，必须询问“是否继续上传图片？还可以继续上传，最多 10 张。”用户明确表示继续后，等待下一张图片；用户明确表示不再上传后，结束图片收集。
   - 当前图片数量达到 10 张时，必须告知已达到最多 10 张并自动结束图片收集，不再询问继续上传。
   - 用户发送无效图片时不得计入数量，必须指出实际失败原因和限制，并要求重新提供；不能进入下一步。
   - 替换图片必须按用户发送顺序保留并映射为 `--replace-images`；声音等非图片元素通过 `--prompt` 描述。成功结束素材收集后，必须明确记录状态已流转至下一步。

5. **创作提示词获取（必填）**：向用户发送话术：“请描述替换图片与参考视频内容的对应关系，以及希望保留或调整的角色、商品、场景、动作、节奏和风格，最长 5000 字符。例如：‘将视频中的 xx 角色替换为图1，xx 商品替换为图2，场景设置为海边’。请根据实际图片序号填写。”用户提供内容后设置 `--prompt`。提示词为空时不得提交任务。成功后必须明确记录状态已流转至下一步。

6. **展示成片信息（强制不可跳过）**：收集完所有参数后，在正式提交前向用户展示：
   - 本地视频或图片仅展示文件名，不得展示绝对路径。
   - 公网 URL 脱敏展示，不得展示签名、token、鉴权参数或其他敏感查询参数。
   - 替换图片必须按实际传入顺序逐项展示，仅展示图片编号、文件名或脱敏 URL，不要求在此步骤说明替换对象。
   - 必须说明已选择的模型、语言和完整创作提示词摘要。

```text
视频元素替换任务信息如下，请进行确认：
- 参考视频：[本地文件名，或脱敏后的公网 URL]
- 替换素材：
  1. 图1：[文件名或脱敏 URL]
  2. 图2：[文件名或脱敏 URL]
- 创作提示词：[用户输入的内容摘要]
- 语言：[用户选择的语言，或中文]
- 生成模型：[Seedance 2.5 / Seedance 2.0 mini]
- 模板 ID：[978755330 / 1028571394]
- 替换元素：[角色 / 场景 / 商品 / 道具 / 声音等]

请确认以上成片信息是否符合您的预期？
```

如果任一参数发生变化，之前的确认立即失效，必须重新展示完整成片信息。

7. **二次确认与合规提示（强制不可跳过）**：用户确认成片信息符合预期后，必须告知：

> ⚠️ 本次任务将会消耗创点，任务发起后创点消耗不可退还。
>
> 请确认您已经阅读并同意了 [虚拟人像合规承诺函](https://www.volcengine.com/docs/6664/2369812?lang=zh) 和 [合规承诺函](https://www.volcengine.com/docs/6664/2369383?lang=zh)。
>
> 请确认您拥有参考视频、替换图片及相关人物和商品素材的合法使用、改编和商业发布权。
>
> 确认请回复我，我将开始提交视频元素替换任务。

只有用户明确回复确认或同意后，才能进入 Phase 1。

### Phase 1: 提交任务

用户完成二次确认后：

1. 读取 `references/CLI前置校验指南.md`，确认 OAuth 登录态有效。
2. 首次调用或参数不确定时执行：

```bash
npm exec -y --registry=https://registry.npmjs.org --package @volcengine/kickart-open-mcp@1.1.x -- kickart-open-cli submit_high_similarity_task_v2 --help
```

3. 参数映射原则：
   - 必填：`--ref-video`、`--replace-images`、`--prompt`。
   - 可选：`--language`。
   - 必填：`--template-id`；Seedance 2.5 使用 `978755330`，Seedance 2.0 mini 使用 `1028571394`。
   - `--replace-images` 按用户确认的顺序传入，使用逗号分隔或重复参数，具体形式以 `--help` 为准。
   - 本地素材直接传绝对路径，由 `submit_high_similarity_task_v2` 自动上传；公网 URL 直接传入。
   - 不传未确认的参数，不通过 shell 字符串拼接用户输入。

4. 执行提交：

```bash
npm exec -y --registry=https://registry.npmjs.org --package @volcengine/kickart-open-mcp@1.1.x -- kickart-open-cli submit_high_similarity_task_v2 \
  --template-id 978755330 \
  --ref-video /absolute/path/to/ref.mp4 \
  --replace-images /absolute/path/to/replace-1.png,/absolute/path/to/replace-2.png \
  --prompt "将视频中的人物替换为图1，将商品替换为图2，保持原视频结构和节奏。" \
  --language zh
```

实际执行时仅传用户确认过的参数。

5. 命令退出码为 `0` 时解析 stdout JSON，提取 `task_id`、`request_id`、`request_body` 和 `raw`，保存到当前会话上下文。
6. 任何失败场景均禁止自动重试提交命令。能够证明请求未发送时，修复问题后也必须重新展示成片信息并取得二次确认；无法确认请求是否已受理时，优先使用已有 `task_id` 查询，不得重复扣费。

### Phase 2: 提交后回复

提交成功后使用以下模板：

```text
✅ 视频元素替换任务已提交成功，任务ID:<任务ID>
⚠️ 任务正在后台执行中，您可以随时通过“查询进度”获取最新状态。
```

用户查询进度时必须读取 `references/任务查询指南.md`，禁止在提交阶段主动轮询。

## 结果通知

### 生成成功

从完成的 JSON 输出中提取成片视频 URL：

```text
视频元素替换成功，请点击链接预览或下载视频：[视频](<提取到的视频URL>)
```

### 生成失败

```text
❌ 视频元素替换任务失败(任务ID:<任务ID>)
- 错误码:<错误码>
- 处理建议:<匹配 SKILL.md 错误规范的处理建议>
```
